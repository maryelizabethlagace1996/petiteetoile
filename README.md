# Petite Étoile — Prototype MVP

Prototype interactif de l'application mobile **Petite Étoile** (enfants de 3 à 10 ans) : habitudes, bons comportements et constellation d'étoiles hebdomadaire.

## Lancer en local

Ouvrir `index.html` dans un navigateur (connexion Internet requise pour Tailwind CSS, Lucide et Google Fonts via CDN).

## Démo

- Code parent : `4826`
- Mot de passe du compte (code oublié) : `Etoile2026`
- Le panneau « Mode présentateur » permet d'accéder directement à chaque écran, de rouvrir l'app ou de réinitialiser la démo.

## Déploiement

Site statique, aucune étape de build : déployable tel quel sur Vercel (framework « Other »).
